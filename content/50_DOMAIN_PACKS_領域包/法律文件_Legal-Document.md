# 法律文件：合約審閱與法務輔助

> **一句話**：針對法律文件場景，提供從合約審閱到法規遵循的 AI 輔助導入路徑。

---

## 領域概述

### 目標讀者

- 企業法務主管 / 法務專員
- 法律事務所合夥人 / 律師
- 合規部門主管
- 法務科技導入負責人

### 核心問題

| 問題 | 傳統做法 | AI 可解決程度 |
|------|---------|--------------|
| 合約初審費時 | 律師逐條閱讀 | **高**（加速初審） |
| 條款比對困難 | 人工比對標準版 | **高**（自動標記差異） |
| 風險條款識別 | 依經驗判斷 | **中高**（輔助識別） |
| 法規變動追蹤 | 定期人工查閱 | **中**（監控通知） |
| 合約資訊抽取 | 人工填表 | **高**（自動抽取） |
| 多語言合約 | 翻譯 + 審閱 | **中高**（翻譯 + 輔助） |

### 重要聲明

```
⚠️ AI 法律輔助聲明

本領域包描述的 AI 應用僅供「輔助」用途：
1. AI 產出不構成法律建議
2. 所有結果需經合格律師審核
3. 最終法律判斷應由專業人員做出
4. 高風險事項（訴訟、重大合約）需格外謹慎

企業應建立明確的人工覆核流程和責任歸屬。
```

## 導入路徑（Roadmap）

### Quick Win（2-4 週）

**目標**：驗證合約輔助可行性，建立信心

| 項目 | 做法 | 成功標準 |
|------|------|---------|
| **合約資訊抽取 PoC** | NDA 關鍵資訊抽取 | 準確率 >90% |
| **條款分類 PoC** | 常見條款類型識別 | F1 >80% |

**測試資料建議**：
- 選擇最常見的合約類型（如 NDA）
- 準備 20-50 份已審閱合約作為測試集
- 標註關鍵欄位和條款類型

**抽取欄位範例（NDA）**：

| 欄位 | 說明 | 必填 |
|------|------|------|
| 當事人 | 甲方、乙方名稱 | 是 |
| 簽約日期 | 合約簽署日期 | 是 |
| 保密期限 | 保密義務期間 | 是 |
| 適用法律 | 準據法 | 是 |
| 例外事項 | 不受保密約束的資訊 | 否 |
| 違約責任 | 違約賠償條款 | 否 |

**預算估算**：
- API 費用：$100-200
- 人力：1-2 人 × 2 週

**Gate**：
- [ ] 關鍵欄位抽取準確率 > 90%
- [ ] 條款分類 F1 > 80%
- [ ] 律師評估認可價值

---

### Pilot（6-12 週）

**目標**：內部試運行，驗證實際效益

| 項目 | 做法 | 成功標準 |
|------|------|---------|
| **合約初審輔助** | 自動標記 + 人工審核 | 審閱時間減少 30% |
| **風險條款提示** | 預設規則 + LLM 識別 | 高風險條款 Recall >90% |
| **合約比對** | 與標準版差異分析 | 差異識別率 >95% |

**風險條款類型**：

| 類型 | 風險等級 | 識別方式 |
|------|---------|---------|
| **無限責任** | 高 | 關鍵詞 + LLM |
| **單方終止權** | 高 | 條款分類 |
| **智財權轉讓** | 高 | 條款分類 |
| **準據法差異** | 中 | 欄位抽取 |
| **保密期過長** | 中 | 欄位抽取 + 規則 |
| **競業禁止** | 高 | 條款分類 |

**預算估算**：
- API 費用：$500-1,500/月
- 人力：2-3 人 × 6-8 週

**Gate**：
- [ ] 審閱時間減少 > 30%
- [ ] 高風險條款 Recall > 90%
- [ ] 無因 AI 錯誤導致的法律問題
- [ ] 律師團隊採用率 > 50%

---

### Production（持續運營）

**目標**：全面部署，持續優化

| 項目 | 做法 | 成功標準 |
|------|------|---------|
| **多類型合約支援** | 擴展至其他合約類型 | 覆蓋主要類型 |
| **法規問答系統** | RAG + 法規資料庫 | 標註來源，不做法律建議 |
| **合約知識庫** | 歷史合約檢索 | 輔助談判參考 |

**預算估算**：
- API 費用：$2,000-8,000/月（依量）
- 維護人力：0.5-1 FTE

## 法律領域專屬考量

### 責任與合規

| 考量 | 說明 | 建議做法 |
|------|------|---------|
| **律師責任** | AI 錯誤誰負責？ | 明確為「輔助工具」，律師最終審核 |
| **保密義務** | 客戶資料保密 | 使用私有部署或合規雲端 |
| **利益衝突** | AI 可能揭露利衝資訊 | 存取權限控制 |
| **記錄保存** | 法律文件保存要求 | 符合法規的資料保留政策 |

### 資料安全要求

```
法律文件 AI 系統安全要求：

1. 資料傳輸：TLS 1.3 加密
2. 資料儲存：加密 at rest
3. 存取控制：RBAC + 審計日誌
4. 資料駐留：確認資料不出境（如需要）
5. 供應商：評估 AI 供應商的資料處理政策
6. 資料保留：符合法規要求的保留/刪除政策
```

### 合規框架

| 法規 | 要求 | AI 系統影響 |
|------|------|-----------|
| **GDPR** | 資料保護、刪除權 | 需支援資料刪除 |
| **律師保密義務** | 客戶資料保密 | 資料處理政策 |
| **金融法規** | 記錄保存 | 審計軌跡 |
| **跨境資料** | 資料傳輸限制 | 資料駐留考量 |

## 風險與緩解

| 風險 | 影響 | 緩解措施 |
|------|------|---------|
| **抽取錯誤** | 遺漏關鍵條款 | 人工覆核必須 |
| **風險漏判** | 未識別高風險條款 | 規則兜底 + 高 Recall 優先 |
| **保密外洩** | 客戶資料洩露 | 安全控制 + 供應商評估 |
| **過度依賴** | 律師失去判斷 | 教育訓練 + 流程設計 |
| **責任不清** | 出錯時歸責困難 | 明確責任歸屬政策 |
| **偏見問題** | AI 可能有偏見 | 人工覆核 + 定期評測 |

詳見：[[幻覺與可追溯性_Hallucination-Grounding]]、[[資料治理與權限_Data-Governance-Access-Control]]

## 常見合約類型設定

### NDA（保密協議）

**抽取欄位**：
- 當事人、簽約日期、保密期限
- 保密資訊定義、例外事項
- 違約責任、準據法

**風險條款**：
- 保密期限過長（>5 年）
- 無例外事項定義
- 單方面義務

### 採購/服務合約

**抽取欄位**：
- 當事人、合約金額、付款條件
- 交付物/服務範圍
- 保固期限、違約責任
- 智財權歸屬

**風險條款**：
- 無限賠償責任
- 智財權全歸對方
- 單方終止權
- 自動續約

### 勞動合約

**抽取欄位**：
- 雇主/員工資訊
- 職位、薪資、福利
- 工作地點、工時
- 競業禁止條款

**風險條款**：
- 競業禁止範圍過廣
- 智財權歸屬不清
- 終止條款不公平
