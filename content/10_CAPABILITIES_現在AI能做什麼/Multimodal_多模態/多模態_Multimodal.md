# 多模態（Multimodal / Vision-Language）

> **一句話**：讓 AI 同時理解圖像和文字，進行圖片分析、文件解讀、視覺問答等任務。

---

## 基本資訊

| 項目 | 內容 |
|------|------|
| **輸入** | 圖像 + 文字 prompt（可選：多張圖、影片幀） |
| **輸出** | 文字回答、分析結果、結構化資料 |
| **成熟度** | **Production-ready**（圖像理解），**Pilot**（複雜推理） |
| **最後更新** | 2025-01-XX |

---

## 1. 能力定義（Definition）

**多模態 AI 的核心能力**：

| 能力 | 說明 | 典型應用 |
|------|------|---------|
| **圖像描述** | 描述圖像內容 | 無障礙、內容審核 |
| **視覺問答（VQA）** | 回答關於圖像的問題 | 客服、分析 |
| **文件理解** | 解讀文件、表格、圖表 | 文件處理、資料抽取 |
| **OCR + 理解** | 識別文字並理解語義 | 發票處理、表單 |
| **圖像推理** | 基於圖像進行推理 | 診斷、品質檢測 |
| **多圖比較** | 比較多張圖像 | 變化偵測、版本比較 |

[F] GPT-4V 在多種視覺理解 benchmark 上達到 SOTA 水準，展現強大的零樣本視覺推理能力[^DOC_GPT4V]。

## 2. 能做到的範圍（What it can do now）

### 2.1 表現良好的場景

- [x] 文件/發票/收據資訊抽取
- [x] 圖表/表格理解與摘要
- [x] 產品圖片分析（電商）
- [x] UI/UX 截圖分析
- [x] 圖像內容描述
- [x] 簡單視覺推理
- [x] 多語言文件 OCR + 翻譯
- [x] 圖像中的物件識別

### 2.2 主流模型比較

| 模型 | 提供商 | 優點 | 缺點 | 適用場景 |
|------|--------|------|------|---------|
| **GPT-4o** | OpenAI | 整合度高、推理強 | 成本較高 | 通用視覺理解 |
| **Claude 3.5 Sonnet** | Anthropic | 文件理解佳、長 context | 圖像數量限制 | 文件處理、分析 |
| **Gemini 1.5 Pro** | Google | 長 context（100 萬 token）、影片理解 | API 限制 | 長文件、影片分析 |
| **Qwen-VL** | Alibaba | 開源、可本地部署 | 需要調優 | 自建系統 |
| **LLaVA** | 開源 | 開源、研究用 | 效能較弱 | 研究、學習 |

### 2.3 能力維度評估

| 維度 | GPT-4o | Claude 3.5 | Gemini 1.5 | 說明 |
|------|--------|------------|------------|------|
| **OCR 準確率** | 極佳 | 極佳 | 極佳 | 各模型都很強 |
| **表格理解** | 佳 | 極佳 | 佳 | Claude 表格處理較強 |
| **圖表分析** | 佳 | 佳 | 佳 | 複雜圖表仍有挑戰 |
| **空間推理** | 中 | 中 | 中 | 相對較弱的領域 |
| **計數準確** | 中 | 中 | 中 | 物件計數常出錯 |
| **多圖處理** | 佳 | 中 | 極佳 | Gemini 長 context 優勢 |

## 3. 適合的任務特徵（Good fit）

這個能力適合的任務通常有以下特徵：

- [x] **圖像品質良好**：清晰、解析度足夠
- [x] **非精確計數**：不需要 100% 準確的數量
- [x] **有文字/結構輔助**：圖像中有文字可參考
- [x] **允許人工覆核**：非完全自動化決策
- [x] **通用場景**：非高度專業領域

---

## 4. 不適合/高風險（Bad fit / Red flags）

### 4.1 不適合的場景

- [ ] **精確計數**：需要準確數量的物件計數
- [ ] **空間精確測量**：需要精確尺寸/距離
- [ ] **醫學影像診斷**：X 光、CT 等專業診斷（需專用模型）
- [ ] **微小細節識別**：圖像中的微小瑕疵
- [ ] **即時影片分析**：高幀率即時處理

### 4.2 紅旗警訊

- [x] **幻覺風險**：可能「看到」不存在的內容
- [x] **隱私風險**：圖像可能包含敏感資訊
- [x] **偏見風險**：人物相關分析可能有偏見
- [x] **過度自信**：對錯誤答案也會很有信心

[I] 多模態模型在視覺幻覺（hallucination）方面仍是挑戰，可能描述圖像中不存在的物件。

## 5. 常用落地模式（Patterns）

| 模式 | 適用情境 | 說明 |
|------|---------|------|
| **文件資料抽取** | 發票、收據、表單 | OCR + 結構化輸出 |
| **圖表分析** | 報告、簡報 | 圖表轉文字/數據 |
| **產品圖分析** | 電商、品管 | 自動生成描述、檢測瑕疵 |
| **UI 分析** | 測試、設計 | 截圖分析、元素識別 |
| **多圖比較** | 版本控制、變化偵測 | 比較前後差異 |
| **圖像 + RAG** | 知識庫搜尋 | 圖像描述 + 向量搜尋 |

## 7. 瓶頸與對策（Bottlenecks & Mitigations）

| 瓶頸 | 症狀 | 緩解策略 |
|------|------|---------|
| **視覺幻覺** | 描述不存在的內容 | 交叉驗證、人工覆核 |
| **解析度限制** | 小字看不清 | 預處理放大、分區處理 |
| **複雜版面** | 表格/圖表理解錯誤 | 分區處理、明確 prompt |
| **成本** | 圖像 token 消耗大 | 壓縮圖像、選擇性處理 |
| **延遲** | 處理時間較長 | 並行處理、快取 |
| **多頁文件** | 頁數限制 | 分頁處理、摘要後合併 |

## 8. 成熟度分級（Maturity）

| 階段 | 定義 | 這個能力的狀態 |
|------|------|---------------|
| **PoC** | 實驗室環境可行 | 容易達成 |
| **Pilot** | 小規模真實環境可行 | 需要評估準確率、建立覆核流程 |
| **Production** | 大規模穩定運行 | 需要完整的品質監控、錯誤處理 |

**Production 需要**：
- 輸入圖像品質檢查
- 輸出結果驗證機制
- 視覺幻覺檢測
- 成本監控

## 9. 成本估算

### API 定價參考（2025-01）

| 服務 | 定價 | 備註 |
|------|------|------|
| **GPT-4o** | 依圖像大小計 token | 低解析度 ~85 token，高解析度 ~170+ token/tile |
| **Claude 3.5 Sonnet** | 圖像計入 input token | 大約 1,000-2,000 token/圖 |
| **Gemini 1.5 Pro** | 圖像計入 token | 約 $1.25/100 萬 token |

### 成本優化策略

| 策略 | 效果 | 適用場景 |
|------|------|---------|
| **降低解析度** | 成本降低 50%+ | 不需要細節的場景 |
| **裁切關鍵區域** | 減少處理量 | 已知目標區域 |
| **預處理 OCR** | 減少模型呼叫 | 純文字抽取 |
| **批次處理** | 減少 overhead | 大量文件 |
