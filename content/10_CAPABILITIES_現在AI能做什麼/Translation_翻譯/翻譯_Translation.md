# 翻譯（Translation）

> **一句話**：讓 AI 進行多語言翻譯，包括文件翻譯、即時翻譯、和特定領域翻譯。

---

## 基本資訊

| 項目 | 內容 |
|------|------|
| **輸入** | 原始語言文本 |
| **輸出** | 目標語言文本 |
| **成熟度** | **Production-ready**（常見語言），**Pilot**（稀有語言/專業領域） |
| **最後更新** | 2025-01-XX |

---

## 1. 能力定義（Definition）

**翻譯任務類型**：

| 任務類型 | 說明 | 典型場景 |
|----------|------|---------|
| **Document Translation** | 完整文件翻譯 | 合約、報告、手冊 |
| **Real-time Translation** | 即時翻譯 | 聊天、客服 |
| **Website Localization** | 網站在地化 | 多語言網站 |
| **Subtitle Translation** | 字幕翻譯 | 影片、會議 |
| **Technical Translation** | 技術文件翻譯 | API 文件、產品規格 |
| **Creative Translation** | 創意內容翻譯 | 行銷文案、品牌內容 |

## 2. 能做到的範圍（What it can do now）

### 2.1 表現良好的場景

- [x] 高資源語言對翻譯（英中、英日、英法等）
- [x] 一般商務文件翻譯
- [x] 技術文件翻譯
- [x] 客服對話翻譯
- [x] 保留格式的文件翻譯（Markdown、HTML）
- [x] 多語言一致性術語處理

### 2.2 表現程度

#### Metrics（評測指標）

| 指標 | 定義 | 適用場景 |
|------|------|---------|
| **BLEU** | N-gram 重疊度 | 通用翻譯品質 |
| **COMET** | 神經網路評分 | 更接近人類判斷 |
| **TER** | 編輯距離 | 後編輯工作量 |
| **Adequacy** | 意義保留程度（人工） | 關鍵內容 |
| **Fluency** | 流暢度（人工） | 可讀性 |

#### 語言對支援程度

| 語言對 | 品質 | 備註 |
|--------|------|------|
| **英 ↔ 中** | 極佳 | 主流需求 |
| **英 ↔ 日** | 極佳 | 商務常用 |
| **英 ↔ 西/法/德** | 極佳 | 歐洲語言 |
| **英 ↔ 韓** | 佳 | 區域需求 |
| **中 ↔ 日/韓** | 佳 | 亞洲語言對 |
| **稀有語言** | 中 | 資料較少 |

#### LLM vs 傳統 NMT 比較

| 面向 | LLM (GPT-4/Claude) | 傳統 NMT (Google/DeepL) |
|------|-------------------|------------------------|
| **一般翻譯** | 極佳 | 極佳 |
| **長文件一致性** | 佳（可控上下文） | 中（分段翻譯） |
| **術語控制** | 極佳（可 prompt） | 中（需詞彙表） |
| **格式保留** | 佳 | 佳 |
| **創意翻譯** | 極佳 | 中 |
| **成本** | 高 | 低 |
| **延遲** | 中 | 低 |

## 3. 適合的任務特徵（Good fit）

- [x] **高資源語言對**：英中、英日等
- [x] **需要術語一致**：可透過 prompt 控制
- [x] **需要語境理解**：長文件、上下文相關
- [x] **創意內容**：需要適當在地化
- [x] **批量處理**：大量文件翻譯

---

## 4. 不適合/高風險（Bad fit / Red flags）

### 4.1 不適合的場景

- [ ] **法律文件正式版**：需專業譯者 + 法律審查
- [ ] **醫療文件正式版**：影響診斷治療
- [ ] **極稀有語言**：訓練資料不足
- [ ] **口語/俚語過重**：難以準確翻譯
- [ ] **即時語音翻譯**：延遲敏感

### 4.2 紅旗警訊

- [x] **術語錯譯**：專業術語翻譯錯誤
- [x] **文化不適**：翻譯不符合目標文化
- [x] **遺漏內容**：長文件部分內容遺失
- [x] **格式破壞**：特殊格式未保留

---

## 5. 常用落地模式（Patterns）

| 模式 | 適用情境 | 品質 | 成本 |
|------|---------|------|------|
| **Pure LLM** | 一般文件、靈活度高 | 高 | 高 |
| **LLM + 術語庫** | 專業領域、術語一致 | 極高 | 高 |
| **NMT + LLM 後編輯** | 大量文件、成本敏感 | 高 | 中 |
| **Pure NMT** | 大量、低成本需求 | 中 | 低 |
| **人機協作** | 關鍵文件 | 極高 | 極高 |

### LLM 翻譯 Prompt 模式

```markdown
你是專業的 [領域] 翻譯專家。

**翻譯規則：**
1. 保持原文格式（標題、列表、表格）
2. 專業術語按照術語表翻譯
3. 保留原始的 Markdown/HTML 標記
4. 不要添加或刪除內容

**術語表：**
- API → API（不翻譯）
- Machine Learning → 機器學習
- [其他術語...]

**請將以下內容從 [原語言] 翻譯成 [目標語言]：**

[原文內容]
```

## 7. 瓶頸與對策（Bottlenecks & Mitigations）

| 瓶頸 | 症狀 | 緩解策略 |
|------|------|---------|
| **術語不一致** | 同詞不同翻譯 | 術語庫 + prompt 控制 |
| **長文件處理** | 上下文丟失 | 分段 + 術語傳遞 |
| **格式破壞** | 標記丟失 | 格式保留 prompt |
| **成本** | Token 費用高 | NMT 預翻譯 + LLM 後處理 |
| **延遲** | 響應慢 | 批次處理、快取 |

## 8. 品質控制

### 翻譯品質檢查清單
