# 對話（Conversation）

> **一句話**：讓 AI 進行多輪自然語言對話，包括客服、助理、角色扮演等場景。

---

## 基本資訊

| 項目 | 內容 |
|------|------|
| **輸入** | 用戶訊息 + 對話歷史 |
| **輸出** | AI 回應 |
| **成熟度** | **Production-ready**（受控場景），**Pilot**（開放場景） |
| **最後更新** | 2025-01-XX |

---

## 1. 能力定義（Definition）

**對話任務類型**：

| 任務類型 | 說明 | 典型場景 |
|----------|------|---------|
| **Task-Oriented** | 完成特定任務 | 客服、訂票、查詢 |
| **Knowledge-Grounded** | 基於知識庫回答 | FAQ、產品問答 |
| **Open-Domain** | 開放式聊天 | 閒聊、陪伴 |
| **Persona-Based** | 角色扮演 | 品牌形象、遊戲 NPC |
| **Copilot** | 輔助用戶完成工作 | 寫作、分析、程式設計 |

---

## 2. 能做到的範圍（What it can do now）

### 2.1 表現良好的場景

- [x] 結構化客服問答（FAQ、產品查詢）
- [x] 表單填寫引導
- [x] 多輪資訊收集
- [x] 基於文件的問答（RAG）
- [x] 任務分解和引導
- [x] 情感感知和適當回應
- [x] 多語言對話

### 2.2 表現程度

#### Metrics（評測指標）

| 指標 | 定義 | 適用場景 |
|------|------|---------|
| **Task Completion Rate** | 任務完成率 | Task-Oriented |
| **First Contact Resolution** | 首次解決率 | 客服 |
| **User Satisfaction (CSAT)** | 用戶滿意度 | 所有場景 |
| **Fallback Rate** | 轉人工比例 | 客服 |
| **Avg. Turns to Resolution** | 平均對話輪數 | 效率指標 |
| **Coherence** | 對話連貫性 | 品質指標 |

#### 對話能力維度

| 維度 | 說明 | LLM 表現 |
|------|------|---------|
| **理解能力** | 理解用戶意圖 | 極佳 |
| **記憶能力** | 記住對話歷史 | 佳（受 context 限制） |
| **推理能力** | 多步驟推理 | 佳 |
| **知識能力** | 回答事實問題 | 中（需 RAG 增強） |
| **情感能力** | 適當情感回應 | 佳 |
| **一致性** | 人設/立場一致 | 中（需 prompt 強化） |

---

## 3. 適合的任務特徵（Good fit）

- [x] **明確邊界**：對話範圍有限定
- [x] **有知識源**：可連接知識庫/文件
- [x] **可接受偶爾錯誤**：有人工兜底機制
- [x] **用戶預期合理**：用戶知道是 AI
- [x] **非安全關鍵**：錯誤不會造成重大損失

---

## 4. 不適合/高風險（Bad fit / Red flags）

### 4.1 不適合的場景

- [ ] **醫療診斷諮詢**：需要專業責任
- [ ] **法律建議**：需要法律責任
- [ ] **金融投資建議**：需要合規
- [ ] **心理危機介入**：需要專業處理
- [ ] **無人工兜底**：完全自主決策

### 4.2 紅旗警訊

- [x] **幻覺回答**：編造不存在的資訊
- [x] **人設漂移**：角色不一致
- [x] **繞過限制**：Jailbreak 攻擊
- [x] **隱私洩露**：透露敏感資訊
- [x] **情感依賴**：用戶過度依賴 AI

---

## 5. 常用落地模式（Patterns）

| 模式 | 適用情境 | 自主度 | 風險 |
|------|---------|--------|------|
| **FAQBot** | 常見問題回答 | 高 | 低 |
| **Guided Flow** | 表單/流程引導 | 中 | 低 |
| **RAG Chatbot** | 知識庫問答 | 中 | 中 |
| **Agent Assistant** | 客服輔助 | 低（輔助人工） | 低 |
| **Autonomous Agent** | 完全自主客服 | 高 | 高 |

### 對話架構模式

```
┌─────────────────────────────────────────┐
│  用戶輸入                                │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│  意圖識別 / 路由                          │
│  - FAQ？→ 知識庫查詢                      │
│  - 任務？→ 任務流程                       │
│  - 投訴？→ 轉人工                         │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│  知識檢索（RAG）                          │
│  - 向量搜尋相關文件                        │
│  - Rerank 排序                           │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│  回應生成（LLM）                          │
│  - System Prompt（人設、規則）             │
│  - 對話歷史                               │
│  - 檢索結果                               │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│  安全過濾                                 │
│  - 敏感內容檢查                           │
│  - 隱私資料脫敏                           │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│  回應輸出                                 │
└─────────────────────────────────────────┘
```

## 8. 安全與合規

### 對話安全考量

| 風險 | 說明 | 緩解措施 |
|------|------|---------|
| **Prompt Injection** | 惡意輸入操控回應 | 輸入過濾、角色分離 |
| **資訊洩露** | 透露系統 prompt 或資料 | 輸出檢查 |
| **不當內容** | 生成有害內容 | 內容過濾 |
| **隱私問題** | 記錄敏感對話 | 資料脫敏、保留政策 |

[F] 86% 的 LLM 應用（36 個中有 31 個）易受 prompt injection 攻擊[^SEC_PromptInjection2023]。

### 合規要求

| 法規 | 要求 | 實作 |
|------|------|------|
| **GDPR** | 資料最小化、刪除權 | 對話資料保留政策 |
| **EU AI Act** | 高風險 AI 透明度 | 明確告知用戶是 AI |
| **消保法** | 不得誤導消費者 | AI 身份揭露 |

## 9. 成熟度分級（Maturity）

| 階段 | 定義 | 這個能力的狀態 |
|------|------|-----------------|
| **PoC** | 實驗室環境可行 | ✅ 極易達成 |
| **Pilot** | 小規模真實環境可行 | ✅ 受控場景成熟 |
| **Production** | 大規模穩定運行 | ⚠️ 需完善安全和兜底機制 |

**Production 需要**：
- 明確的對話範圍邊界
- 人工兜底機制
- 安全過濾系統
- 對話監控和告警
- 用戶回饋收集

## ROI 估算

### 客服場景

| 指標 | 傳統客服 | AI 輔助 | AI 自主 |
|------|---------|---------|---------|
| **處理量** | 50 件/天/人 | 100 件/天/人 | 500+ 件/天 |
| **人力成本** | $3,000/月 | $3,000/月 | $500/月(API) |
| **首次解決率** | 70% | 85% | 60% |
| **可用時間** | 8 小時 | 8 小時 | 24 小時 |

### 建議混合模式

```
L1: AI 自主處理（簡單問題）→ 60% 工單
L2: AI 輔助人工（複雜問題）→ 30% 工單
L3: 純人工處理（敏感問題）→ 10% 工單
```

**效益**：整體人力需求減少 40-60%
