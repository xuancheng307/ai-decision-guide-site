# AI 能力與落地手冊 - 使用指南

> **一句話定位**：這是一個「AI 可行性判斷 + 落地劇本（Playbook）」知識庫。
> 任何人拿著某個領域/流程問題，都能在這裡完成「能不能做、怎麼做、用什麼、卡在哪、值不值得」的判斷。

---

## 這個知識庫能回答什麼問題？

| 你的問題 | 去哪裡找答案 |
|----------|--------------|
| AI 現在能做什麼？到什麼程度？ | `10_CAPABILITIES/` 能力卡 |
| 怎麼做到？架構？步驟？ | `20_PLAYBOOKS/` 落地劇本 |
| 有哪些工具？怎麼選？ | `30_TOOLBOX/` 工具卡 |
| 會卡在哪？怎麼避坑？ | `40_BOTTLENECKS/` 瓶頸卡 |
| 某領域/某公司怎麼用 AI？ | `50_DOMAIN_PACKS/` 領域包 |

## 快速開始

### 情境 1：我想知道「某任務 AI 能不能做」

1. 打開 [AI 可行性判斷流程](AI可行性判斷流程_一頁版.md)
2. 把你的問題拆成「流程 → 任務」
3. 對每個任務查對應的能力卡
4. 得到：能/不能/有條件能

### 情境 2：我想幫公司導入 AI

1. 打開 [小公司導入 SOP](小公司導入SOP_從0到1.md)
2. 先做 [導入前必問 20 題](評估表_導入前必問20題.md)
3. 選一個 Quick Win 任務開始 PoC
4. 按 Playbook 執行，過 Gate 才往下

### 情境 3：我想評估某領域的 AI 機會

1. 打開 `50_DOMAIN_PACKS/` 找對應領域
2. 如果沒有，用 [Domain Pack 模板](../TEMPLATES/DomainPack.md) 自己做一份
3. 得到：任務清單、可行性評分、解法組合、導入路線

## 內容類型速查

| 類型 | 用途 | 回答什麼問題 |
|------|------|--------------|
| **能力卡** | 定義 AI 能做什麼 | 能/不能/到什麼程度 |
| **劇本 Playbook** | 怎麼做到 | 架構、步驟、驗收 |
| **工具卡** | 工具選型 | 用什麼、何時用、替代方案 |
| **瓶頸卡** | 風險與避坑 | 會卡哪、怎麼解 |
| **領域包** | 完整診斷 | 某領域如何用 AI |

## 防止失焦的判準

新增任何內容前，問自己：

> **它能不能讓我對某個領域的某個任務做出更好的「可行性判斷」？**

- 能 → 放進對應的卡片或領域包
- 不能 → 放到 `60_UPDATES/` 或刪除

---

## 成功判準（Definition of Done）

這個知識庫「可用」的標準：

1. **任意領域**能在 10-30 分鐘產出「AI 如何幫助」的方案草案
2. **每個常見任務**都有：能力卡 + 落地劇本 + 工具箱 + 瓶頸卡
3. **能對小公司**提出可執行的導入路線（PoC → Pilot → Production）
