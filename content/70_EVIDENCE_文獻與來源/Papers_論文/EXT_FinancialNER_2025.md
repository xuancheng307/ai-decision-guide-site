# Financial Named Entity Recognition: How Far Can LLM Go?

## Citation

**標題**: Financial Named Entity Recognition: How Far Can LLM Go?
**arXiv**: [2501.02237](https://arxiv.org/abs/2501.02237)
**時間**: January 2025

---

## Supports Claims（可引用的主張）

### [F] 可直接引用的事實

1. **研究目標**：評估 SOTA LLM 在金融領域 NER 任務上的能力。

2. **評測模型**：評估 GPT-4o、LLaMA-3.1 和 Gemini-1.5。

3. **Prompting 技術**：測試三種 prompting 技術：direct prompting、in-context learning、chain-of-thought (CoT) prompting。

4. **評測資料集**：使用 FiNER-ORD 資料集，包含 201 篇人工標註的金融新聞文章。

### [I] 可推論的主張

1. 領域特定 NER 可能需要專門評測。
2. 不同 prompting 策略對 NER 效能有顯著影響。
